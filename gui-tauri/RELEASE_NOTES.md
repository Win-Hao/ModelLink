ModelLink 2.2.0 — 界面重做，思考深度和 Auto 模式跟着 Claude 走

升级后打开 ModelLink，点一次「应用到 Claude Desktop」就能用上这些。配置文件不用动。
升级前开着的对话如果提示「模型槽位 … 未映射到任何服务商」，在 Claude 里给它重新选一个模型即可。

界面
- 整个界面重做：顶部导航、更大的窗口、新的深色模式
- 概览页一眼看清 Claude → ModelLink → 服务商这一路通不通，每个模型标着「已生效」还是「未应用」（看的是 Claude 那边真正写着的配置）
- 「应用到 Claude Desktop」固定在页头；第一次用有三步引导
- 请求日志加上耗时、token 用量和花费；出错的请求用大白话说明原因，并带你去改

在 Claude 里
- 模型选择器里直接出现思考深度（最多 5 档），选哪档就按哪档发给服务商
- 每个模型在 Claude 里用哪个代号可以自己选，增删模型不会打乱别的模型
- Auto 模式的安全检查优先交给 claude-sonnet-5 上的模型，新加的模型默认先放这里；日志里标出每一次安全检查
- Chat 里会告诉模型它这一次实际是哪个模型，免得它把自己认成 Claude 或别的模型
- 设置页新增「一键使用 Winhao 的配置」：Auto 模式、高级文件分析等 Claude 工作区开关一次调好
- 设置页新增「一键排查」：连不上、模型不见了、突然变贵了，点一下看问题出在哪

费用和稳定性
- 费用按各家服务商官方价计算，费率从 models.dev 自动同步；有模型查不到价格就不显示花费，不再按 Anthropic 官方价估算
- Claude 请求了没配置的模型时直接报错，不再悄悄换成第一个模型回答
- 开着 1M 上下文但模型其实装不下时，界面直接标出真实上限
- 服务商不认思考参数、思考预算太小等报错，自动修复后重试
- 长回答期间自动保活，减少中途断流
- 连不上服务商、服务商没填地址的请求也会记进日志
