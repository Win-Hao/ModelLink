ModelLink 2.1.0 — 跟随 Claude Desktop 进化

**Claude 里终于能逐次调推理强度了**

- 换用 Claude Desktop 原生支持的模型槽位，模型选择器里直接出现 5 档推理强度（low / medium / high / Extra / max）与 auto 思考模式 —— 以前只能在 ModelLink 里按服务商设一次，用户在 Claude 里选了也没用
- 服务商上的「推理强度」改名「默认推理强度」：桌面端选了什么就用什么，这里只在桌面端没指定时兜底
- 模型数上限从 8 提到 20

**费用不再是假账单**

- 新增真实费率表，Usage 页显示的费用按你实际用的服务商计价，不再按 Anthropic 官方价估算
- 费率从 models.dev 自动同步（社区维护的开源模型数据库，6 小时一次），也可手填覆盖
- 订阅制方案（Kimi Code、百炼 Token Plan 等）正确显示为 0

**不再有「悄悄换了个模型」**

- Claude 请求了没配置的槽位时直接报错，不再静默改用第一个模型（旧行为可在设置页开回来）
- 模型开着 1M 上下文但上游其实装不下时，界面直接标出真实上限 —— 新增模型不再默认开 1M

**长生成不断流**

- 上游思考期间由 ModelLink 往 Claude 发保活心跳，配合更长的空闲超时，治长回答中途断掉

**上游报错自动修复**

- 上游不认推理强度、thinking 预算过小、验不了历史思考块签名时，自动改写重试，并记住这家的能力，你完全无感
- 修复过的请求在日志里有标记

**其它**

- Chat 标签页默认开启（此前需手动开）；免去每次启动选部署模式
- 「深度探测」按钮：一次问清这家服务商支持到什么程度（推理强度档位、会不会静默回落模型、缓存透传、1M 支持）
- 组织级自定义指令；可选的模型身份说明（默认开，实测能让模型正确报出自己是谁）
- Claude 出网代理设置（http/https）
- 会话标题生成自动降到最省档，每开一个新会话省下约 88 个思考 token
- 按检测到的 Claude Desktop 版本决定写哪些键，老版本不会被写坏

**升级提示**：本版换了模型槽位，升级后首次打开会提示「新版为你的模型启用了 Claude Desktop 原生推理强度选择器」，点一次「应用到 Claude Desktop」即可生效。配置文件无需迁移。
